Convert this portfolio into a full-stack Node.js + Express app 
with a password-protected Admin CMS panel.

TECH STACK:
- Node.js + Express backend
- Replit DB for data storage (import with: 
  const Database = require("@replit/database"))
- Frontend: same HTML/CSS/JS design system 
  (black, silver, Bebas Neue, DM Sans)
- All portfolio pages served dynamically from Express

---

FILE STRUCTURE:
/
├── server.js          (Express app, all routes)
├── package.json
├── /public
│   ├── index.html     (now template, data injected)
│   ├── style.css
│   └── admin/
│       ├── index.html (admin dashboard)
│       └── admin.css
├── /views
│   ├── project.html   (dynamic case study template)
└── .env               (ADMIN_PASSWORD=yourpassword)

---

SERVER ROUTES:

GET  /                    → serve portfolio homepage, 
                            inject projects from DB
GET  /project/:slug       → serve case study page, 
                            inject project data from DB
GET  /admin               → redirect to /admin/login 
                            if not authenticated
GET  /admin/login         → serve login page
POST /admin/login         → check password from .env, 
                            set session cookie, 
                            redirect to /admin/dashboard
GET  /admin/dashboard     → main CMS dashboard (protected)
POST /api/projects        → create new project
PUT  /api/projects/:id    → update project
DELETE /api/projects/:id  → delete project
POST /api/upload          → handle image upload, 
                            return image URL
GET  /admin/logout        → clear session, 
                            redirect to login

Use express-session for auth. 
Session secret from .env: SESSION_SECRET=randomstring
If session not found on any /admin route → 
redirect to /admin/login

PORTFOLIO RENDERING:
In index.html (served by Express), replace all 
hardcoded project cards with a template literal loop 
over projects from DB where visible === true, 
sorted by order field.

In project.html (case study), use the slug from 
URL params to fetch the right project from DB 
and inject all fields into the template.

Use a simple templating approach — 
replace {{placeholders}} in HTML strings server-side 
before sending response.

SECURITY:
- Admin password stored in .env, never in DB
- All /admin/* and /api/* routes check session
- If no valid session → redirect to /admin/login
- Add basic rate limiting on login route: 
  max 5 attempts, then 5 min lockout
  (store attempt count in memory object)
